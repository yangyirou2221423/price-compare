# 价策 · 智能比价与购买策略引擎

> 不只告诉你哪里便宜，而是生成一套可执行、可解释、可验证的最省购买方案。

「价策」是一个面向 3C / 家电消费场景的比价与购买策略演示作品：把平台价、店铺券、平台券、满减、会员价、百亿补贴、国补、以旧换新、返利放进同一个模型里，求解“在哪买、怎么买、能省多少”，并输出每一步的依据。

- **H5 演示**：uni-app 编译的网页版，浏览器直接打开。
- **微信小程序**：同一套 Vue 3 代码编译到 `mp-weixin`，可导入微信开发者工具。
- **后端求解服务**：FastAPI + SQLite，独立引擎模块，便于测试与复现。
- **数据说明**：全部价格与优惠为演示数据；不抓取平台页面；国补与平台规则为可配置示例。

---

## 1. 竞赛定位与价值

**技术开发类竞赛潜力约 8/10；如果只做“价格聚合”约 5/10。** 差异不在“比价”本身，而在下面三件事：

1. **优惠叠加求解**：优惠之间有门槛、互斥、顺序、上限和资格约束，组合出最低实付本质上是一个带约束的组合优化问题。
2. **政策规则引擎**：国补、地区加码、以旧换新做成 JSON 规则，带版本与生效期，可解释地判定资格。
3. **从“最低价”到“购买步骤”**：输出可执行的领券顺序、凑单建议、拆单方案，并解释哪些优惠为什么没采用。

详细评估、差异化与答辩叙事见 [docs/competition-value.md](docs/competition-value.md)。

## 2. 已实现功能

### P0 核心

- 首页：搜索、热门比价、国补计算器入口、价格侦探信号。
- 商品比价：4 个平台（京东 / 淘宝 / 拼多多 / 抖音）按到手价排序，价格拆解瀑布。
- 最优策略：活动价 → 店铺券 → 平台券/满减 → 会员 → 国补 → 以旧换新 → 返利，逐步展示与解释。
- 国补资格引擎：按地区、品类、价格上限、以旧换新判定；示例规则可配置、带版本与生效期。
- 价格历史：90 天演示曲线、中位价/最低价/分位、先涨后降识别。
- 收藏、降价提醒入口、用户提交价格（轻量）。
- H5 + 微信小程序双端。

### P1 进阶

- 购物车跨平台拆单：≤6 件商品精确枚举，平台券/满减按订单维度计算。
- 凑单建议：差多少门槛、加购什么、加购后实付净增多少。
- 京东联盟 / 淘宝客 / 多多进宝适配层接口（Mock 实现，真实接入需资质）。
- 用户提交价格并记录到 SQLite（可在“我的”中删除）。

### 关键演示数字（演示规则）

| 场景 | 结果 |
|---|---|
| P001 星海 X1 Pro 手机 | 拼多多标价 5299，淘宝叠加店铺券 400 + 国补 500 后实付 **5099**，最优平台反转 |
| P002 灵越 Air 14 笔记本 | 无 88VIP 时京东 4269.10；开通 88VIP 后淘宝 4103.14，计入返利净价 **4021.08** |

## 3. 技术架构

```
uni-app (Vue 3 + TypeScript + Pinia)
  ├─ H5        → 评委直接打开 / 录屏
  └─ mp-weixin → 微信开发者工具 / 体验版
          │  HTTPS / JSON
FastAPI (Python 3.12)
  ├─ API：商品 / 比价 / 策略 / 购物车 / 历史 / 规则 / 提交
  ├─ 引擎：rules + stacker + cart_solver + explain + history
  ├─ 数据：SQLAlchemy 2 + SQLite
  └─ 适配器：Mock / JDUnion / TaobaoKe / PDD
          │
    data/seed/catalog.json + 价格历史生成器
```

## 4. 快速启动（Windows）

### 4.1 后端

本机演示环境使用 `backend/.venv`（不会提交到仓库）。首次在新环境运行时：

```bash
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

启动（首次会自动建表并载入演示数据）：

```bash
cd backend
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 健康检查：<http://127.0.0.1:8000/api/health>
- OpenAPI：<http://127.0.0.1:8000/docs>
- 数据库：`backend/data/pricecompare.db`（删除后重启即可重新生成种子数据）

也可以直接双击 `scripts/start-backend.bat`。

### 4.2 H5

```bash
cd frontend
npm install
npm run dev:h5 -- --host 127.0.0.1 --port 5173
```

打开 <http://127.0.0.1:5173>。

> 本机演示环境使用 `tools/node-v22.23.5-win-x64` 便携版（不提交到仓库）。其他环境安装 Node 20+ 后直接使用 `npm`；本机找不到 `node/npm` 时可双击 `scripts/dev-h5.bat`。
>
> 前端默认请求 `http://127.0.0.1:8000`；可用 `VITE_API_BASE` 覆盖，见 `frontend/.env.example`。

### 4.3 微信小程序

```bash
cd frontend
npm run build:mp-weixin
```

用微信开发者工具导入 `frontend/dist/build/mp-weixin`。

- 演示 AppID 为 `touristappid`，可在 `src/manifest.json` 换成自己的 AppID。
- 本地 API 调试：开发者工具 → 详情 → 本地设置 → 勾选“不校验合法域名”。
- 手机体验版需要 HTTPS 合法域名；H5 是答辩主演示路径，避免现场域名/网络问题。

### 4.4 测试与构建

```bash
cd backend
.venv/Scripts/python.exe -m pytest -q

cd ../frontend
npm run type-check
npm run build:h5
npm run build:mp-weixin
```

也可以双击 `scripts/build-all.bat`。

## 5. 演示路径（5 分钟）

1. **首页**：看到 12 件商品与“价格侦探”信号；点开 P001 星海手机。
2. **比价详情**：拼多多标价 5299 最低，但淘宝叠加 400 店铺券 + 500 国补后实付 **5099**；展开价格瀑布。
3. **策略**：展示“领店铺券 → 国补”两步，以及备选平台与未采用优惠的原因。
4. **条件切换**：打开右上角条件，勾选 88VIP；P002 笔记本的最优平台从京东变为淘宝（4269.10 → 4103.14）。
5. **购物车**：清空后点“载入示例购物车（3 件）”，得到京东 + 淘宝拆单 **6538**；加购 89 元收纳盒后 **6327**。
6. **国补计算器**：手机 5999 / 淘宝 → 500；切到京东 → 0，并解释“平台不参与”。
7. **价格走势**：P001 拼多多曲线标出“疑似先涨后降”、当前分位 1.1%。

完整脚本见 [docs/demo-script.md](docs/demo-script.md)。

## 6. 数据与合规

- **不抓取平台页面**，不绕过反爬、不破解签名。
- 演示数据来自 `data/seed/catalog.json`，页面与文档均标注“演示数据”。
- 预留联盟 API 适配层：京东联盟、淘宝客、多多进宝；真实接入需资质与商务授权，且接口以推广为主，不保证全网比价。
- 用户提交只保存商品、平台、价格、备注；收藏与购物车仅存本地。
- 国补规则为示例，实际以当地最新政策、平台页面和实名资格为准。
- 详细说明见 [docs/compliance.md](docs/compliance.md)。

## 7. 性能与正确性

- 单商品：6 条优惠平均 **0.39ms**，14 条平均 **10.2ms**（p95 34.2ms）。
- 购物车：3 件平均 **6.9ms**；5 件平均 **199.5ms**；6 件平均 **829ms**（p95 943ms）。
- 23 项自动化测试通过；单商品剪枝求解与无剪枝暴力枚举做随机差分测试。
- 完整测试记录与复现命令见 [docs/test-report.md](docs/test-report.md)。

## 8. 已知限制与下一步

- 小程序手机体验版受 HTTPS 合法域名与平台审核约束；当前以 H5 + 开发者工具演示为主。
- 价格为演示数据，不可当作实时售价；联盟 API 仅预留接口。
- 购物车模型假设同一平台商品合并为一单，平台券/满减按订单小计计算；未覆盖多店铺、多地址、预售等复杂场景。
- 未接入真实支付、订单与返利提现；不构成交易闭环。
- 下一步：接入联盟开放平台、截图 OCR 识券、用户价格众包审核、规则运营后台、软著与论文材料。
