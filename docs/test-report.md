### 差分测试

随机生成 100 组小规模优惠（3–6 条，含固定/百分比、门槛、互斥组），同时运行：

- 分支限界求解器；
- 无剪枝暴力枚举。

比较 `final_price` 与 `net_price`，全部一致。该测试验证剪枝和记忆化没有改变最优解。

## 6. 性能基准

命令：

```bash
cd backend
.venv/Scripts/python.exe -m app.engine.benchmark
```

单商品（120 个随机实例/档）：

| 优惠数 | 平均 | P95 | 最大 |
|---:|---:|---:|---:|
| 6 | 0.394 ms | 0.713 ms | 1.114 ms |
| 10 | 2.151 ms | 5.391 ms | 9.958 ms |
| 14 | 10.204 ms | 34.175 ms | 55.751 ms |

购物车：

| 商品数 | 用例 | 平均 | P95 | 最大 |
|---:|---:|---:|---:|---:|
| 3 | 60 | 6.864 ms | 8.856 ms | 11.463 ms |
| 5 | 60 | 199.496 ms | 223.587 ms | 254.015 ms |
| 6 | 20 | 829.358 ms | 943.011 ms | 951.128 ms |

结论：单商品远低于 200ms 目标；6 件购物车低于 1s 目标。6 件以上改用启发式，并在响应中标注。


6. 我的 → 提交价格 → 查看最近提交。
