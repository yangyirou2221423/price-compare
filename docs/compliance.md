# 数据来源与合规说明

> 本文件用于竞赛答辩、作品说明与后续真实上线前的合规自查，不构成法律意见。

## 1. 基本原则

1. **不抓取平台页面**：不绕过反爬、不破解签名、不模拟登录、不批量请求电商平台。
2. **不宣称实时全网最低价**：演示数据不是实时售价，页面与文档均明确标注。
3. **数据最小化**：只收集完成比价所需的最少信息。
4. **规则可追溯**：国补/平台规则带来源、版本、生效期。
5. **用户可删除**：用户提交的价格记录提供删除接口与入口。

## 2. 数据源

| 数据源 | 用途 | 当前状态 | 合规要点 |
|---|---|---|---|
| 内置模拟数据 | 竞赛演示、算法验证 | 已实现 | 页面标注“演示数据”；不冒充实时价格 |
| 用户主动提交 | 补充价格 | 已实现 | 只存商品、平台、价格、备注；可删除 |
| 本地收藏/购物车 | 用户体验 | 已实现 | 仅存浏览器/小程序本地，不上传 |
| 京东联盟 | 商品/推广数据 | 适配层预留 | 需官方账号、应用审核、签名与接口权限 |
| 淘宝客（阿里妈妈） | 商品/推广数据 | 适配层预留 | 需账号资质，遵守推广协议 |
| 多多进宝 | 商品/推广数据 | 适配层预留 | 需账号资质，遵守平台协议 |
| 抖音精选联盟 | 商品/推广数据 | 适配层预留 | 需账号资质，遵守平台协议 |
| 页面爬虫 | —— | **不实现** | 违反平台协议，技术上也易失效 |

### 为什么不做爬虫

- 违反平台用户协议与 robots 约定；
- 需要绕过反爬/签名/风控，合规风险高；
- 页面结构频繁变化，竞赛演示不稳定；
- 把违规能力当卖点，答辩风险极高。

## 3. 演示数据声明

- 12 个商品、47 条报价、6 条补贴规则、90 天价格历史均为**模拟数据**。
- 品牌与型号为虚构或示意，不对应真实商品；平台名称为说明性使用。
- 页面统一显示“演示数据”徽标；首页页脚与详情页均有提示。
- 演示数据中的“国补仅淘宝参与”“浙江加码”等设定是为了展示引擎能力，**不是真实政策**。
- 不展示平台 Logo，不暗示与任何平台存在合作或授权关系。

推荐文案：

> 本作品中的价格、优惠、补贴与规则均为演示数据，仅用于验证比价与优惠叠加逻辑，不代表实时售价或政策承诺。实际购买请以平台结算页和当地最新政策为准。

## 4. 政策与补贴规则

- 国补、地区加码、以旧换新规则为 JSON 示例，带 `source`、`version`、`effective_from/to`。
- 规则金额按商品价格与比例估算，未考虑：
  - 地区名额与申请顺序；
  - 实名/身份资格；
  - 平台结算差异；
  - 旧机检测结果；
  - 政策临时调整。
- 页面注明“示例规则”“以当地最新政策为准”，不构成政策承诺或法律意见。
- 正式上线前应安排运营人员按官方文件更新规则，并保留规则版本与变更记录。

## 5. 用户数据

### 收集

用户提交价格时仅保存：

- 商品 ID；
- 平台 ID；
- 用户填写的价格；
- 可选备注。

不收集：姓名、手机号、身份证、地址、支付信息、平台账号、Cookie。

### 存储

- 收藏、购物车、地区/会员/旧机估值：仅存本地 `uni.setStorageSync`。
- 价格提交：存 SQLite `submissions` 表，演示环境无账号体系。
- 求解请求快照：`strategy_runs` 保存请求与结果，用于复现；不含身份信息。

### 删除

- 提供 `DELETE /api/submissions/{id}`。
- “我的 → 最近提交”每条记录有“删除”入口。
- 本地数据可通过“重置本地演示数据”一键清空。

### 保留期限

演示环境不设自动过期；竞赛结束后可删除数据库文件 `backend/data/pricecompare.db` 重建。

## 6. 平台名称与商标

- 仅以文字方式提及京东、淘宝、拼多多、抖音，用于说明比价场景。
- 不使用平台 Logo、不复制平台页面样式、不暗示官方合作。
- 如后续真实上线，应取得必要授权或采用更中性的“平台 A/B/C”表述。

## 7. 微信小程序审核注意事项

| 事项 | 说明 |
|---|---|
| 主体与类目 | 个人主体可选工具/信息查询类目；涉及电商交易可能需要企业资质 |
| AppID | 演示用 `touristappid`；正式版需注册并替换 |
| request 合法域名 | 手机体验版/正式版需 HTTPS 域名并配置白名单；本地开发可勾选“不校验合法域名” |
| 隐私保护指引 | 如收集用户信息，需在公众平台配置隐私保护指引 |
| 外链限制 | 小程序不能直接打开淘宝/京东链接；采用展示步骤 + 复制口令 |
| 比价内容 | 不宣称“全网最低”，不使用绝对化用语；标注数据来源与更新时间 |
| 诱导分享 | 不做强制分享/诱导分享 |

## 8. 安全实践

- 联盟 API 凭证不写入仓库，使用环境变量/密钥管理。
- 开发环境 CORS 允许所有来源；生产应收紧到具体域名。
- SQLAlchemy 参数化查询，避免 SQL 注入。
- 用户输入有长度/数值校验（Pydantic）。
- 不执行用户提交的链接内容；只存字符串。
- 不在客户端保存任何平台账号凭证。

## 9. 真实接入联盟 API 的前置条件

1. 注册并审核通过对应联盟账号；
2. 申请应用与接口权限；
3. 实现签名、限流、重试与缓存；
4. 遵守数据展示、归因、佣金结算与禁止转售条款；
5. 在页面展示数据来源与更新时间；
6. 建立数据下架/纠错机制；
7. 如涉及用户画像，补充隐私政策与授权。

## 10. 竞赛伦理

- 明确区分“演示数据”与“真实价格”；
- 不把模拟的政策平台限制说成真实政策；
- 不夸大算法效果，性能数字附环境与复现命令；
- 不把爬虫、破解、绕审作为能力展示；
- 对评委的“数据从哪来”问题，主动说明适配层与合规路径。
